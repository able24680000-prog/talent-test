对标案例拆解

BENCHMARKS

这类"身份代入型"测试在小红书上不是新物种——能跑出来的，靠的都是同一套结构。以下案例来自已拆解的店铺与在售商品（数据为 2026 年 10 月实测截图）。

案例一 · 同店在售

「你像哪个历史人物？」趣味测试

出现在 Moopuffy 店铺商品列表里（与天赋测试同店），封面是手写笔记本风：「你像哪个 历史人物？」配两个古风小人。卖点不是测得准，而是对号入座的名人锚点——测出"你像李白"，比测出"你文艺倾向 82 分"想转发一百倍。

可借鉴：结果必须落到一个有名有姓的身份上。本 demo 的每种命格都配了"与你相近的历史人物"，就是抄的这一招。

案例二 · 已验证的爆款模型

Moopuffy「天赋测试-挖掘自身」¥1.88

同店当月热销第 1 名，已售 5.7 万+、店铺评分 4.7。玩法是全自动 H5：50 道题 → 即时生成 4 页报告（类型命名 + 雷达图 + 霍兰德代码 + 职业推荐 + 行动计划），零人工交付，所以 ¥1.88 的冲动价也跑得动量。店铺粉丝仅 2314，靠的是爆文带货，不是私域。

可借鉴：结构照搬、题材换皮。本 demo 保留了它被验证的骨架（答题 → 图谱 → 类型解读 → 出路建议 → 分享卡），把"职业方向"换成古代人更上头的"身份 + 结局"。

案例三 · 同店在售

「测一测你适合的城市」

同店另一款测试商品：基于生活偏好匹配理想城市。证明这家店的打法是一个引擎、多款皮肤：天赋、历史人物、城市……答题引擎不变，换个题材就是一款新商品。

可借鉴：古代身份是最适合做"系列"的皮肤——测完身份可以续测"你在古代怎么发财""你的古代CP是谁"，一道流量吃三遍。本 demo 先把第一款跑通。

为什么押注古代题材

身份 + 天赋 + 结局 = 天然的晒单结构

现代天赋报告晒的是分数，古代命盘晒的是故事：「我是镇边将军，结局是马革裹尸但青史留名」——有反差、有判词、有不服（"凭什么我是商人"），评论区自己就吵起来了。而评论权重恰恰是小红书 CES 里最贵的一项。

本 demo 的差异化：不只给身份，还给"这一生怎么过完"。结局的转折一幕，就是专门为评论区预留的钩子。
